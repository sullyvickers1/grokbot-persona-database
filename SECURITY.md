# Security

This repository is a collection of prompts and schemas. It should contain **no secrets**.

## Do not contribute

- API keys, tokens, private model endpoints
- Exploit code, malware, or step-by-step intrusion recipes
- Instructions for self-harm or for concealing assets / evading lawful process

Professional personas discuss risk at a defensive level of detail. If a file crosses into weaponization, open a bug and it will be pulled.

## Reporting

If you find a prompt that can be reasonably read as assistance for a crime or for self-harm, open a private report with the repository owner or a public issue labeled `security` if the content is already public and you are only flagging it.
