# Templates

| File | Use |
| --- | --- |
| [persona.template.yaml](persona.template.yaml) | Start here. Every required field, with comments. |
| [persona.minimal.yaml](persona.minimal.yaml) | Short skeleton that still validates if you fill the prompt floor. |

New files go in `personas/<category>/<id>.yaml`. Run `npm run validate` before you open the PR. Read [CONTRIBUTING.md](../CONTRIBUTING.md).
